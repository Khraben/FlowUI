## [Unreleased]

### Added

- Button component with 7 variants (primary, secondary, success, danger, close, clear, icon)
- Input component with 7 types (text, number, search, select, password, time, date)
- DatePicker component with locale support and customizable calendar colors
- SelectInput wrapper component
- TimeInput component with AM/PM support
- 3 size options (sm, md, lg) for all components
- Icon positioning support (left/right)
- Loading states for buttons
- Password visibility toggle
- Clear button functionality
- Full TypeScript support with strict mode
- Tailwind CSS 4 integration
- Customizable color props for all components
- Component constants exported for type-safe usage
